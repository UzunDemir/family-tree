# 🌳 Семейное древо Узун

Интерактивное генеалогическое древо на D3.js с эффектом «ухода предков в бесконечность».

## ✨ Возможности

- **Клик по карточке** — плавный зум + подсветка всей родословной ветки
- **Наведение** — тултип с датой рождения и номером поколения
- **Колесо мыши** — зум, перетаскивание — панорама
- **Эффект бесконечности** — далёкие предки бледнеют и уменьшаются
- **Аватары** — круги с инициалами (замена фото на будущее)
- **Кнопки управления** — сброс, зум, скрытие линий
- **Адаптив** — работает на телефоне
